
# 🔹 1) `if` Statement

### ✅ Definition

The `if` statement is the most basic decision-making construct. It executes a block of code **only when a specified condition evaluates to true**.

### ✅ Syntax

```c
if(condition){
    // statements
}
```

### ✅ Key Points

* Condition must return **true (non-zero)** or **false (0)**.
* If the condition is false, the block is skipped.
* Used when you want to execute something **only in one case**.

### ✅ Example

```c
int age = 20;
if(age >= 18){
    printf("Eligible to vote");
}
```

### 🎯 Interview Insight

Used for **single condition checking** where no alternative action is required.

---

# 🔹 2) `if-else` Statement

### ✅ Definition

The `if-else` statement provides an **alternative execution path** when the condition is false.

### ✅ Syntax

```c
if(condition){
    // true block
} else {
    // false block
}
```

### ✅ Key Points

* Exactly **one block will execute**.
* Improves decision-making when there are **two possible outcomes**.

### ✅ Example

```c
int num = 5;
if(num % 2 == 0){
    printf("Even");
} else {
    printf("Odd");
}
```

### 🎯 Interview Insight

Best used when there are **binary decisions (Yes/No, True/False)**.

---

# 🔹 3) Nested `if-else`

### ✅ Definition

A nested `if-else` means placing an `if` or `if-else` statement **inside another if or else block**.

### ✅ Syntax

```c
if(condition1){
    if(condition2){
        // statements
    } else {
        // statements
    }
}
```

### ✅ Key Points

* Used when decisions depend on **multiple conditions hierarchically**.
* Can become complex → should be used carefully.

### ✅ Example

```c
int age = 20;
int hasID = 1;

if(age >= 18){
    if(hasID){
        printf("Allowed");
    } else {
        printf("ID required");
    }
} else {
    printf("Not allowed");
}
```

### 🎯 Interview Insight

Shows **multi-level decision-making**, but excessive nesting reduces readability → consider alternatives like logical operators.

---

# 🔹 4) `if-else` Ladder

### ✅ Definition

An `if-else` ladder is used when multiple conditions need to be checked **sequentially**.

### ✅ Syntax

```c
if(condition1){
    // block 1
}
else if(condition2){
    // block 2
}
else if(condition3){
    // block 3
}
else{
    // default block
}
```

### ✅ Key Points

* Conditions are checked **top to bottom**.
* First true condition executes, rest are skipped.
* `else` is optional but recommended as default.

### ✅ Example

```c
int marks = 85;

if(marks >= 90){
    printf("Grade A");
}
else if(marks >= 75){
    printf("Grade B");
}
else if(marks >= 50){
    printf("Grade C");
}
else{
    printf("Fail");
}
```

### 🎯 Interview Insight

* Preferred when dealing with **multiple mutually exclusive conditions**.
* Avoid too many conditions → can impact performance and readability.

# 💡 Final Interview Comparison

| Type           | Use Case                      | Complexity |
| -------------- | ----------------------------- | ---------- |
| if             | Single condition              | Low        |
| if-else        | Two choices                   | Low        |
| Nested if-else | Multiple dependent conditions | Medium     |
| if-else ladder | Multiple independent choices  | Medium     |

---

# 🚀 Pro Tips (Important for Interviews)

* Use **logical operators (`&&`, `||`)** to reduce nesting.
* Prefer **switch-case** over long `if-else ladder` when possible.
* Always maintain **readability and indentation**.
* Avoid **deep nesting** → makes debugging difficult.

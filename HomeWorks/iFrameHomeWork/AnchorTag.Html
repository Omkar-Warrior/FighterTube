Anchor Tag in HTML

📌 HTML Anchor tag is used to create links between webpages.

🔗 It allows users to move from one page to another or open files and emails.

✨ Anchor Tag:

🔴 <a> -> Defines a hyperlink.

🧠 Basic Syntax:
Link Text

🌐 href attribute -> Specifies the destination link.

Example:
Visit Google

🎯 Open link in new tab:
Use target attribute.

Example:
Open Google in new tab

📩 Send Email using anchor tag:
Use mailto.

Example:
Send Email

📄 Download file using anchor tag:
Example:
Download Notes

📍 Link to a section of same page:
Example:
Go to Top

🚀 Anchor tag is one of the most important tags for website navigation.

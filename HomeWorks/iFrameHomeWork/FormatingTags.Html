Formating Tags in Html

📌 HTML Formatting tags are used to make text look special and meaningful on a webpage.

📖 They help highlight important words and improve readability.

✨ Common Formatting Tags in HTML:

🔴 <b> -> Makes text **bold** without extra importance.
Example: This is bold text

🟠 <strong> -> Makes text **important and bold** (used for SEO and screen readers).
Example: This is important text

🟡 <i> -> Makes text *italic*.
Example: This is italic text

🟢 <em> -> Makes text *emphasized* (important italic text).
Example: This is emphasized text

🔵 <mark> -> Highlights text like a marker.
Example: This is highlighted text

🟣 <small> -> Displays smaller text.
Example: This is small text

🟤 <del> -> Shows deleted text (strikethrough).
Example: This text is deleted

⚫ <ins> -> Shows inserted text (underlined).
Example: This text is inserted

🔷 <sub> -> Subscript text (used in chemistry formulas).
Example: H2O

🔶 <sup> -> Superscript text (used in maths).
Example: 102

🚀 Formatting tags improve readability, accessibility and make webpages attractive.

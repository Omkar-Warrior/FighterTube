Table Tag in HTML

📌 HTML Table tag is used to display data in rows and columns.

📊 It is useful for showing structured information like marks, reports, schedules, etc.

✨ Table Tags:

🔴 <table> -> Used to create a table.

Example:





🟠 <tr> -> Table Row (creates a row).

🟡 <td> -> Table Data (creates a cell).

Example:


  

    Omkar
    90
  




🟢 <th> -> Table Heading (bold and centered by default).

Example:


  

    Name
    Marks
  




🔵 <caption> -> Adds title to the table.

Example:


  Student Marks



🟣 rowspan -> Merges rows.

Example:
A

🟤 colspan -> Merges columns.

Example:
Total

🚀 Tables help organize and present data clearly in structured format.
